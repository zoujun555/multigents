写 `{{req_dir}}selftest.md`，第一行是下面三者之一：

- `RESULT: PASS`：构建通过，现有测试通过，验收标准都已实现。
- `RESULT: FAIL`：尽力后仍有构建或测试失败。
- `RESULT: BLOCKED`：缺少必须由人提供的信息或环境。

之后写：改了哪些文件（每个一句话说明）、构建命令和结果、测试命令和结果（通过/失败数量）、每条验收标准的实现情况、偏离 spec 的地方及原因、遗留问题。
